# Contributing to SunoSaathi

SunoSaathi is a student research prototype. Team members should create a branch for each feature, describe the change clearly, and open a pull request before merging into `main` when time permits.

## Suggested branch names

```text
feature/sound-classifier
feature/isl-recognition
feature/alert-manager
feature/dashboard
fix/demo-audio
```

## Before committing

- Do not commit datasets, model weights, private recordings, API keys, or personal information.
- Run the relevant local test or demo.
- Update documentation if the behavior or setup changes.
- Mark unfinished features clearly as `planned` or `prototype`.

## Commit style

Use short, descriptive messages such as:

```text
add sound event label mapping
add prototype alert severity logic
update hackathon demo instructions
fix microphone sample-rate handling
```
